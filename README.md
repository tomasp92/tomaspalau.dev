# tomaspalau.dev

Personal site of Tomás Palau Posse — Full Stack Engineer · Tech Lead.

Next.js 16 (App Router), React 19, plain CSS. Bilingual (EN/ES): the language is picked from the browser and can be toggled.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- Content (both languages): `lib/content.js`
- Layout and sections: `app/Portfolio.js`
- Styles (light/dark via `prefers-color-scheme`): `app/globals.css`
- CV served from `public/cv/Tomas_Palau_Posse_CV.pdf`
